SOFZZZZ WORLD - NEW VERSION

1. Replace your existing app/page.tsx with app/page.tsx from this package.
2. Replace your existing app/globals.css with app/globals.css from this package.
3. Copy public/anbe-en-anbe.mp3 into your project's public folder.
4. Run:
   npm run dev

IMPORTANT:
- The song is placed outside the animated scene, so it does NOT restart when the world changes.
- The song starts when "Open your world" is clicked because browsers normally block sound autoplay before user interaction.
- It loops continuously across the whole experience.
